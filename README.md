# Air Route Finder

## Overview
The Air Route Finder is a Python application that utilizes the A* algorithm to find the shortest path between airports. The application features a graphical user interface (GUI) built with CustomTkinter, allowing users to select starting and destination airports and visualize the route on a canvas.

## Features
- **Graph Representation**: The air route graph is represented as an adjacency list, where each airport is a node and the edges represent the distances between them.
- **A* Pathfinding Algorithm**: The application implements the A* algorithm, which combines the benefits of Dijkstra's algorithm and heuristic-based search to efficiently find the shortest path.
- **Interactive GUI**: Users can select airports from dropdown menus and visualize the route on a canvas.
